# Abhay Singh Chauhan — Portfolio

A custom editorial/developer portfolio built with pure HTML, CSS and JavaScript.

## Design direction
- Off-black + warm paper palette
- Orange accent with muted lime terminal accent
- Editorial typography
- Terminal/build-log motif
- No blue SaaS gradient theme
- No glassmorphism-heavy UI
- No fake skill percentages
- Responsive layout

## Files
- `index.html` — portfolio content and links
- `style.css` — complete UI and responsive styles
- `script.js` — scroll reveal + back-to-top behavior
- `Abhay-Singh-Chauhan-Resume.pdf` — resume download

## Run locally
Open `index.html` directly or use VS Code + Live Server.

## GitHub Pages
```bash
git init
git add .
git commit -m "Build custom developer portfolio"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/abhay-portfolio.git
git push -u origin main
```
Then enable GitHub Pages from **Settings → Pages → Deploy from branch → main → / (root)**.
